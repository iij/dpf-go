# データモデル: ゾーン単位の排他のラベルをゾーンへ移す

**機能**: [spec.md](./spec.md) | **計画**: [plan.md](./plan.md) | **日付**: 2026-09-29

排他が扱う値と、その検証規則・状態遷移・エラーを定める。決定の根拠は
[research.md](./research.md) を参照。

## 1. 排他の状態

**置き場**: 対象ゾーンのラベル **1 つ**。

| 項目 | 値 |
|---|---|
| キー | `lock.dpf-go`（公開定数 `ZoneLockLabelKey`。[research.md](./research.md) D8） |
| 値 | `<保持者>-<奪ってよい時刻の 10 桁>` |
| 値の長さ | 12〜43 文字（保持者 1〜32 + 区切り 1 + 10 桁） |
| 消費するラベル | 1 個（ゾーンの上限 10 個のうち。利用者は 9 個使える） |

```text
web01.tokyo-12345-a1b2c3d4-1790319252
└────── 保持者（1〜32 文字）──────┘│└─ 奪ってよい時刻（Unix 秒 10 桁）─┘
                                   └─ 区切り（'-'）
```

**読み出しは右端から固定幅で行う。** 末尾 10 文字を奪ってよい時刻、その直前の 1 文字を区切り
として確かめ、残りを保持者とする。この読み方により**保持者に区切り文字が含まれていても曖昧に
ならない**（[research.md](./research.md) D2）。

**ゾーンのラベルは未反映の編集の概念を持たない。** レコードのラベルと異なり「更新予定」の
状態が無く、ゾーン反映を必要としない。書き込みは非同期に確定する。

## 2. 保持者

| 規則 | 値 | 違反時 |
|---|---|---|
| 長さ | 1〜32 文字 | 32 文字超は `ErrOwnerTooLong`（書き込みを試みない） |
| 空文字 | 既定の保持者へフォールバック | エラーにしない（006 の Option の作法） |
| 文字種 | 制約なし | — （右端から読むため区切り文字を含んでもよい） |

**既定の保持者**（[research.md](./research.md) D3）:

```text
<ホスト名（枠 15 文字）>-<PID>-<乱数 8 桁 hex>
```

- ホスト名の枠は **15 文字に固定**する。超える場合は**先頭を残して右側を落とす**。同じホスト
  なら常に同じホスト名部分になる
- PID はゼロ詰めしない（1〜7 桁）
- 全体は 26〜32 文字。乱数の取得に失敗した場合は乱数を落とす（現行の挙動を維持。この場合
  同一ホスト・同一 PID の再実行と区別が付かない）

## 3. 一時レコード追加ロック（006 から継承。変更しない）

| 項目 | 値 |
|---|---|
| 目的 | **ゾーンのラベルの読み取りから書き込みまでの区間**を排他する（006 D11） |
| 実体 | 専用レコードを「追加予定」の状態で作る。重複の拒否が編集者に依らないため、ユーザをまたいで機械的に効く |
| 名前 | ゾーン名の左に `_dpf-go-lock` を足した FQDN（006 D4） |
| ラベル | `owner.lock.dpf-go` と `deadline.lock.dpf-go` の 2 つ（レコードのラベル。1 つに詰めない） |
| 寿命 | 排他の取得の間だけ。取得の成否によらず取り消す。**権威サーバへ公開しない** |

ゾーン名は SOA レコードの `name` から得て、`Mutex` の中に保持する（2 回目以降は読み直さない。
[research.md](./research.md) D5）。

## 4. 状態遷移

```text
                        ゾーンのラベル `lock.dpf-go`
                                    │
        （無し = 一度も取得されていない）
                                    │
                  取得 ─────────────┤ 一時レコード追加ロックの保護下で
                                    │ 「読んで判定し、書く」
                                    ▼
                    <保持者>-<未来の時刻>  ← 保持中
                                    │
                  延長 ─────────────┤ 保持者が自分であることを確かめ、
                                    │ 時刻だけを進める
                                    ▼
                    <保持者>-<過去の時刻>  ← 解放済み
                                    │
                  解放 ─────────────┘ 保持者が自分であることを確かめ、
                                      時刻を現在時刻にする（**ラベルは削除しない**）
```

- **ラベルは削除しない**（仕様 FR-002b）。削除すると「一度も取得されていない」状態と区別が
  付かなくなる。したがって一度でも排他を取得したゾーンは、以降ラベルを 1 つ保持し続ける
- 取得の判定は「ラベルが無い」または「奪ってよい時刻が現在時刻以前」のときに可能とする
- **取得・延長・解放のいずれもゾーン反映を伴わない。ゾーンに未反映の編集を作らない**
  （仕様 FR-002・FR-003）

## 5. エラー

| エラー | 意味 | 返る場面 |
|---|---|---|
| `ErrStillLock`（006） | まだ奪えない | 取得。事前判定・保護下の判定・一時ロックを取れない・書き込みを確認できない |
| `ErrNotLockHolder`（006） | 保持者でない | 延長・解放。保持中に奪われた場合を含む |
| `ErrLabelLimit`（006、**意味を変更**） | **ゾーンの**ラベルの枠が足りない | 取得（書き込みを試みない）。待っても解消しないため、待機の指定があっても待たない |
| `ErrOwnerTooLong`（新規） | 保持者が 32 文字を超える | 取得（書き込みを試みない）。待機の指定があっても待たない |
| `ErrRecordNotFound`（既存） | SOA レコードが見つからない | ゾーン名の取得 |

- `ErrLabelLimit` は**値を流用**し、godoc と文言を「ゾーンのラベル」へ改める。`errors.Is` に
  よる既存の分岐は壊れない（[research.md](./research.md) D9）
- API 由来のエラーはラップせずそのまま返す。`*dpf.GenericOpenAPIError` として `errors.As` で
  取り出せる状態を保つ（006 から継承）

## 6. 検証規則の一覧

| 対象 | 規則 | 違反時 | 要件 |
|---|---|---|---|
| 保持者の長さ | 1〜32 文字 | `ErrOwnerTooLong`（書き込まない） | FR-005d |
| 保持者の空文字 | 既定へフォールバック | — （成功） | FR-005e |
| 消費するラベル | 1 個 | 実装上、2 個になる経路が無い | FR-005b・SC-009 |
| ゾーンのラベルの個数 | 排他を足して 10 個以内 | `ErrLabelLimit`（書き込まない） | FR-006 |
| 値の形式 | 末尾が「区切り + 10 桁」 | 形式が崩れている場合は取得可能として扱う（他者が壊した値に引きずられない） | FR-005b |
| 奪ってよい時刻 | Unix 秒。10 桁に満たない場合は 0 で詰める | — | — |
| 解放 | ラベルを削除しない | 実装上、削除する経路が無い | FR-002b |
| ゾーン反映 | 取得・延長・解放のいずれも行わない | 実装上、反映する経路が無い | FR-002・FR-003 |

## 7. 現行（SOA のラベル）との対比

| 観点 | 現行 | 本機能 |
|---|---|---|
| 置き場 | SOA レコードのラベル 2 つ | ゾーンのラベル 1 つ |
| 未反映の編集 | 保持中も解放後も 1 件残る | **作らない** |
| ゾーン反映の要否 | 解放を確定させるには必要 | **不要** |
| 一括置き換えとの関係 | 排他を解く（007 が特別扱い） | **影響しない** |
| レコードのラベルの消費 | SOA の 10 個のうち 2 個 | **0 個** |
| ゾーンのラベルの消費 | 0 個 | 1 個（一度取得すると恒久） |
| 他ユーザの手作業の編集 | 止まる（未実測の効果） | **止まらない** |
| 2 者の同時取得 | 一時レコード追加ロックで機械的に防ぐ | **同じ（変わらない）** |
| 保持中の尊重 | 奪ってよい時刻を読んで譲る（協調的） | **同じ（変わらない）** |
