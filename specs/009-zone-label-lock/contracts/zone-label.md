# 契約: ゾーンのラベルによる排他

**機能**: [spec.md](../spec.md) | **計画**: [plan.md](../plan.md) | **日付**: 2026-09-29

排他の状態をゾーンのラベルで表すときの不変条件と手順を定める。

## 1. 不変条件

1. **ゾーンのラベルの読み取りから書き込みまでは、一時レコード追加ロックの保護下で行う。**
   この区間の外で判定した結果を使って書き込んではならない（006 から継承）
2. **書き込みはマップ全体の置き換えである。** `PUT` は渡したマップでラベルを置き換えるため、
   **読み取った他のラベルをすべて含めて書き戻さなければならない。** 排他のラベルだけを渡すと
   利用者のラベルが消える
3. 一時レコード追加ロックの専用レコードは、取得の成否によらず取り消す。権威サーバへ公開して
   はならない（006 から継承）
4. 排他の操作はゾーン反映を行わない。ゾーンに未反映の編集を作らない
5. 解放はラベルを削除せず、奪ってよい時刻を現在時刻へ更新する

## 2. 取得の手順

```text
1. ゾーン名を得る（保持済みなら省く）
   └─ SOA レコードを 1 件読み、その name をゾーン名とする
2. 保持者の長さを検証する
   └─ 32 文字超なら ErrOwnerTooLong（以降へ進まない）
3. 事前判定
   └─ ゾーンのラベルを読む。奪えない場合は ErrStillLock（以降へ進まない）
4. 一時レコード追加ロックを取得する
   └─ 取れない場合は ErrStillLock
5. 保護下で再判定する（**3 の結果は使わない**）
   ├─ ゾーンのラベルを読み直す
   ├─ 奪えない場合は ErrStillLock（7 へ）
   └─ 排他のラベルを足すと 10 個を超える場合は ErrLabelLimit（7 へ）
6. 書き込みと確定の確認
   ├─ 読み取ったラベルへ排他のラベルを足したマップを PUT する
   └─ 自分が書いた値が読み出せるまで待つ。確認できない場合は ErrStillLock（7 へ）
7. 一時レコード追加ロックを解放する（**5・6 の成否によらず行う**）
   └─ 解放を確認できない場合は、取得を成功として返さない
```

**事前判定を置く理由**: 取得できない場合が多数を占めるため、専用レコードの作成（POST と
取り消しで 4 回の呼び出し）を避けられる（006 から継承）。**事前判定の結果は保護下では使わない。**

## 3. 延長の手順

一時レコード追加ロックは**取らない**（006 D11。競合しうる相手は「奪ってよい時刻を過ぎたと
判断して奪った者」だけであり、一時ロックを被せても防げる誤りが増えない）。

```text
1. ゾーンのラベルを読む
2. 保持者が自分でなければ ErrNotLockHolder
3. 奪ってよい時刻を進めた値を PUT する（他のラベルを含めて書き戻す）
4. 自分が書いた値が読み出せるまで待つ
   └─ 他者に奪われていた場合は ErrNotLockHolder
```

## 4. 解放の手順

一時レコード追加ロックは取らない。

```text
1. ゾーンのラベルを読む
2. 排他のラベルが無ければ、何もせず成功とする
3. 保持者が自分でなければ ErrNotLockHolder（他者の排他を変更しない）
4. 奪ってよい時刻を現在時刻にした値を PUT する（他のラベルを含めて書き戻す）
```

**確定の確認は行わない**（現行の `Unlock` と同じ。解放の確認まで待つ必要は無い）。

## 5. 値の破損への耐性

他者が `lock.dpf-go` の値を書き換えた、あるいは人が手で付けた結果、形式（末尾が「区切り +
10 桁」）を満たさない値になっている場合がある。

**扱い**: 形式を満たさない値は「排他が成立していない」とみなし、取得を可能とする。解釈できない
値に引きずられて、ゾーンが永久に取得できない状態にならないようにする。

**根拠**: 排他は奪ってよい時刻によって成立する。読めない値は「時刻が分からない」ことであり、
保守的に振る舞うと回復手段が無くなる。上書きすれば正常な状態へ戻る。

## 6. 現行との違い（実装の対応）

| 現行の要素 | 本機能での扱い |
|---|---|
| `getSOA`（編集予定を優先して SOA を読む） | **排他の判定には使わない。** ゾーン名の取得だけに縮小し、結果を保持する |
| `patchLabels`（SOA のラベルを PATCH） | ゾーンのラベルの `PUT` に置き換える |
| `verify`（書いた値が読めるまで待つ） | 対象をゾーンのラベルへ変える。作法は変えない |
| ラベル 2 つの読み書き | 1 つの値の組み立てと、右端から固定幅での読み出しに置き換える |
| `consumedByZoneApply`（一括置き換えが排他を解く申告） | **実装しない**（仕組みは残す。[research.md](../research.md) D11） |
| 一時レコード追加ロック（`acquireLockRecord` ほか） | **変更しない** |
