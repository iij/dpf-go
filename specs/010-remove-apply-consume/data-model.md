# データモデル: 一括置き換えが排他を解くことの申告の仕組みを取り除く

**機能**: [spec.md](./spec.md) | **計画**: [plan.md](./plan.md) | **日付**: 2026-09-29

本機能が扱うのは内部の状態である。取り除く前と後の対照で示す。

## 1. 排他を保持したままの実行が持つ状態

`RunLocked`（および `Mutex.Do`、`ZoneApplier.Apply`）が実行中に持つ状態。

| 項目 | 取り除く前 | 取り除いた後 |
|---|---|---|
| 排他を失ったことの記録 | 保持する | **変わらず保持する** |
| 自動延長を止める仕組み | 保持する | **変わらず保持する** |
| **この先で排他が解かれることの印** | 保持する | **無くなる** |
| 印を立てる操作 | ある（延長の停止も兼ねる） | **無くなる** |
| 印を読み出す操作 | ある | **無くなる** |

印を立てる操作は自動延長の停止も行っていた。停止は終了時にも行われるため、**印が無くなっても
延長が止まらなくなることは無い。**

## 2. 終了時の解放の判定

| 解放の結果 | 取り除く前 | 取り除いた後 |
|---|---|---|
| 成功 | 成功 | **成功**（変わらず） |
| 「保持者でない」で失敗、印が**無い** | そのエラーを返す | **そのエラーを返す**（変わらず） |
| 「保持者でない」で失敗、印が**ある** | 成功として扱う | — （**印が立つ経路が無いため、この行は現在も通らない**） |
| その他の失敗 | そのエラーを返す | **そのエラーを返す**（変わらず） |

**実際に通る行は変わらない。** 表から消えるのは、現在も通らない 1 行だけである。

## 3. 排他の実装が申告できること

| 申告 | 取り除く前 | 取り除いた後 |
|---|---|---|
| 延長の間隔（公開。外部の実装も行える） | ある | **変わらず ある** |
| 一括置き換えが排他を解くか（非公開。外部の実装は行えない） | ある。**行う実装は 0 件** | **無くなる** |

## 4. 検証規則

| 対象 | 規則 | 違反時 |
|---|---|---|
| 公開されている要素 | 差分が無いこと | 本機能の前提が崩れる。取り除く対象を誤っている |
| 排他の取得・延長・解放 | 結果が変わらないこと | 既存の単体テストが落ちる |
| 一括置き換え | 結果が変わらないこと（反映の後も保持され、終了時に解放される） | 既存の単体テスト・統合テストが落ちる |
| 到達しないコード | 残らないこと | `make check-lint` の未使用の検出で分かる |
